# A Little Something for You ❤️

A personal, mobile-responsive interactive letter and date-planner built with vanilla HTML, CSS, and JavaScript.

## Quick Configuration Checklist
1. **Audio File:** Place your song inside `assets/our-song.mp3`.
2. **Optional Personal Photos:** Place up to two Manali photos inside `assets/manali-1.jpg` and `assets/manali-2.jpg` (automatically falls back to scenic mountain/chai imagery if omitted).
3. **Email Notification URL:** Deploy `google-apps-script.gs` on [script.google.com](https://script.google.com) and paste the Web App URL into `CONFIG.GOOGLE_APPS_SCRIPT_URL` at the top of `script.js`.

## Privacy & Hosting Notice
GitHub Pages hosts static repositories publicly. Any audio or image files placed inside the `assets/` folder of a public GitHub repository are publicly accessible via the site URL. Only upload music and photos that you are comfortable hosting on a public URL and have permission to share.
